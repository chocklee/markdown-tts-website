# 听 Markdown — 设计文档

> 日期：2026-08-12
> 状态：已确认（待用户最终审阅）
> 范围：网站首版（iOS 应用为独立后续项目）

## 1. 背景与目标

创建一个公开网站，访客粘贴或上传 Markdown 文件后，即可边看边听 AI 朗读。免费用户使用浏览器自带语音；付费用户购买积分，使用云端高质量语音及 Pro AI 功能。

目标用户：需要「把文字变成声音」的阅读者（通勤、学习、做家务时收听）。

## 2. 核心流程

1. 访客粘贴文本或上传 `.md` 文件（UTF-8）→ 渲染为排版好的文章
2. 点击播放 → 语音按句子朗读，当前句高亮跟随
3. 未登录：浏览器语音，完整基础功能
4. 已登录 + 有积分：可选云端 AI 音色，按用量扣积分；可使用 Pro AI 功能

## 3. 功能范围

### 3.1 基础功能（免费）

- 内容输入：粘贴 / 上传 `.md` 文件（UTF-8，大小上限 5MB）
- 朗读控制：播放、暂停、上一句/下一句、进度条拖动、语速 0.5x–2.0x、音量
- 章节控制：上一章 / 下一章（按大纲标题移动；无标题时按钮禁用）
- 朗读增强：当前句高亮、章节跳转（点击大纲）、跳过代码块 / 表格开关、记住上次位置（未登录存本地）
- 云语音降级：免费用户仅浏览器语音（Web Speech API）

### 3.2 Pro 功能（登录 + 扣积分）

| 功能 | 说明 | 计费方式 |
|---|---|---|
| 云端 AI 音色 | 高质量云语音替代浏览器语音 | 按朗读字数扣积分 |
| 讲解模式 | AI 把原文改写成通俗讲解稿再朗读 | 按改写后字数扣积分 |
| 多语言收听 | 选择目标语言，先翻译再朗读 | 按翻译后字数扣积分 |
| 逐句模式 | 每句朗读后自动停顿，留思考时间 | 登录解锁，不额外扣积分（播放行为）；云语音仍按字数计费 |
| 文档问答 | 播放中打开对话侧栏，围绕文档提问 | 按提问条数扣积分 |

### 3.3 明确不做（首版）

- iOS 应用（独立项目，预留 API 复用）
- 多人协作、评论互动
- 账号找回的复杂流程（仅基础邮件重置）
- 精细音色管理（多音色试听对比）

## 4. 页面结构与界面

共 6 个页面：

| 页面 | 内容 |
|---|---|
| 首页 | 标语、粘贴/上传入口、功能亮点、积分购买入口 |
| 文件列表页 | 我的文档库：最近文件、重命名、删除、重新打开 |
| 阅读器页（核心） | 大纲 \| 正文 \| 右侧滑出面板；底部播放条 |
| 个人中心 | 积分余额、消费记录、购买积分按钮 |
| 积分购买页 | 套餐选择 + 支付（Stripe / 支付宝 / 微信） |
| 登录/注册页 | 邮箱密码 |

阅读器页布局：

- 左栏：当前文件大纲（点击跳转章节）
- 中栏：Markdown 渲染正文 + 当前句高亮
- 右上角按钮：「⚙️ 朗读设置」「💬 文档问答 (Pro)」，点击后各自从右侧滑出面板（互斥），播放不中断
- 底部播放条：上一句 / 播放暂停 / 下一句、上一章 / 下一章、进度条、时间、语速、音量、积分余额

## 5. 积分与计费模型

### 5.1 成本基准（官方价格，2026-08 抓取，汇率 1 USD ≈ ¥7.2）

| 用途 | 模型 | 官方价格 | 折算人民币 |
|---|---|---|---|
| 云语音朗读 | `gpt-4o-mini-tts` | $12 / 100 万字符 | ≈ ¥0.000086 / 字 |
| 文本改写 / 翻译 | `gpt-4o-mini` | 输入 $0.15 / 输出 $0.60 / 100 万 token | 1 万字原文+产物 ≈ ¥0.011 |
| 文档问答 | `gpt-4o-mini` | 同上 | 5 万字文档提问 1 次 ≈ ¥0.012 |

### 5.2 积分映射（售价系数 3x，覆盖支付手续费、服务器、价格波动）

| 功能 | 计费规则 | 用户视角 |
|---|---|---|
| 云语音朗读 | 100 字 = 3 积分 | 1 万字 = 300 积分 = ¥9 |
| 讲解模式 | 改写后 100 字 = 4 积分 | 1 万字讲解稿 = ¥12 |
| 多语言收听 | 翻译后 100 字 = 4 积分 | 1 万字译文 = ¥12 |
| 文档问答 | 20–30 积分/次，按文档长度分级 | 短文档 20，长文档 30 |

- 1 积分 ≈ ¥0.03（人民币区，按体验包折算）；美元区按套餐标价折算约 $0.0045–$0.01/积分（体验包单价高、畅听包单价低，引导用户选大包）
- 音频缓存命中不扣积分（没有产生实际成本）
- 注册赠送 500 积分（体验云音色）

### 5.3 套餐定价

| 套餐 | 人民币 | 美元 | 积分 | 约可朗读 |
|---|---|---|---|---|
| 体验包 | ¥6 | $1.99 | 200 | 2 万字 |
| 轻量包 | ¥25 | $3.99 | 800 | 8 万字 |
| 畅听包 | ¥68 | $9.99 | 2,200（含 10% 赠送） | 22 万字 |

说明：

- 积分是统一虚拟货币，两区共用同一积分池
- USD 直接标定，不做实时汇率换算；汇率大幅变动时手动调价
- Stripe 小额手续费占比高（$1.99 套餐约 33%），定位为拉新尝鲜；若不合算，最低档可提到 $2.99
- 所有消耗参数（模型、单价、售价系数、套餐）放配置中心，可随时调整

### 5.4 防亏损机制

- 每笔消费记录真实 API 成本（供应商 + 用量 + 金额），成本/收入比可视化
- 问答按文档长度分级扣费，防止长文档刷量
- M2 上线后使用真实消费日志校准一次定价

## 6. 技术架构

单仓库 Next.js 全栈（React + TypeScript，App Router）。

### 6.1 前端

- 6 个页面（见第 4 节）
- 阅读器：Markdown 解析渲染（remark/unified + rehype-sanitize）、句子切分、高亮跟随、播放控制（Web Speech API + 云端音频流）
- 滑出面板：朗读设置、文档问答（流式对话）
- 未登录内容存浏览器本地（localStorage/IndexedDB），登录后「保存到文件库」

### 6.2 后端（Next.js API）

- 认证：邮箱密码 + JWT（httpOnly Cookie）
- 积分：账户、流水、订单
- TTS 代理：持有 API Key，前端零接触
- LLM 服务：讲解改写、翻译、文档问答（流式）
- 音频缓存：文本指纹 + 音色 + 语速
- 朗读策略：按句流式合成（点播即出声、跳句零延迟、按需计费），不做整篇预合成

### 6.3 基础设施

- 数据库：PostgreSQL + Prisma ORM
- 部署：海外 Vercel；国内上线需服务器 + ICP 备案
- 监控：Sentry + 成本日志
- 支付：Stripe（美元区）先行，支付宝/微信（国内）后续接入

## 7. 语音供应商抽象层

供应商可插拔为第一等设计原则：

- 统一接口：`synthesize(text, voiceId, speed) → audio`，所有供应商实现同一契约，前端不感知供应商
- 音色中性化：前端只显示统一音色 ID（如「中文女声 1」），配置中心映射到当前供应商的具体音色；切换供应商只改配置，不改代码
- 配置中心驱动：当前供应商、音色映射、单价参数全部可配置；页面音色列表由后端接口动态下发
- 成本日志：每笔合成记录真实成本，与积分定价共用
- 适配器清单：OpenAI TTS（默认）、Azure TTS、豆包、MiniMax、智谱（按需实现）

## 8. 数据模型

| 表 | 说明 |
|---|---|
| `users` | 邮箱、密码哈希（bcrypt/argon2）、币种/地区 |
| `documents` | 标题、Markdown 内容、内容哈希；关联用户（未登录时仅存本地） |
| `credit_accounts` | 用户积分余额 |
| `credit_transactions` | 充值/消费/赠送/退款 + 功能类型 + 实际成本 |
| `orders` | 订单：渠道、金额、币种、状态、对应积分、外部支付 ID |
| `audio_cache` | 文本指纹 + 音色 + 语速 → 音频，命中次数 |
| `qa_conversations` / `qa_messages` | 文档问答会话与消息 |

## 9. 安全设计

1. API Key 只存服务端环境变量
2. 密码强哈希；JWT 认证；登录、合成接口限流
3. 积分防刷：服务端校验余额 + 幂等键防重复扣费；扣费与合成同事务，失败自动退款
4. 内容安全：上传大小限制 5MB；Markdown 渲染过 rehype-sanitize 防 XSS；LLM 提示注入防护（文档内容视为不可信输入）
5. 支付安全：Stripe Webhook 签名校验、订单状态机（pending → paid → 到账，幂等）、金额只信服务端
6. 数据：数据库备份、敏感字段加密

## 10. 合规

- 国内上线：ICP 备案 + 支付宝/微信支付企业资质（先办资质，再接入）
- 生成内容审核：讲解/翻译输出过内容审核
- 隐私条款：明确「用户文档内容不用于训练模型」

## 11. 实施里程碑

| 里程碑 | 内容 | 验收标准 |
|---|---|---|
| M1 核心朗读闭环 | 粘贴/上传 → 渲染 → 浏览器语音播放 + 高亮 + 播放控制（上/下句、上/下章、语速、跳过代码/表格） | 不登录可完整收听免费版 |
| M2 云语音 + 积分 | 邮箱注册/登录、积分账户、TTS 代理、按字扣积分、音频缓存、消费记录页、逐句模式（Pro 解锁） | 云音色可用，扣费准确，余额实时更新 |
| M3 Pro AI 功能 | 讲解模式、多语言收听、文档问答（流式） | 三个功能可用并按规则扣积分 |
| M4 支付 | Stripe 集成、积分购买页、订单到账 | 国际用户可自助购买并到账 |
| M5 国内上线准备 | 支付宝/微信接入、备案、部署、监控、成本校准 | 国内用户可支付；成本/收入比可视化 |
| iOS 应用（独立项目） | 复用同一套 API | 另行规划 |

每个里程碑单独编写实施计划。首个实施计划覆盖 M1。
